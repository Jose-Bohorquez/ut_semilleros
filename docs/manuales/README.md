# Manuales — Sistema de Semilleros IDEAD (Semilleros UT)

RNF04: manual de usuario por rol, manual técnico y manual de instalación.

| Manual | Para quién |
|---|---|
| [manual_administrador.md](manual_administrador.md) | Administrador del sistema |
| [manual_administrativo.md](manual_administrativo.md) | Administrativo |
| [manual_lider_semillero.md](manual_lider_semillero.md) | Líder de semillero |
| [manual_estudiante.md](manual_estudiante.md) | Estudiante (app instalable / PWA) |
| [manual_tecnico.md](manual_tecnico.md) | Desarrollador o técnico que da mantenimiento |
| [manual_instalacion.md](manual_instalacion.md) | Técnico que instala el sistema (local o en un servidor nuevo) |

**Cómo se validan** (RNF04, criterio de aceptación): un usuario nuevo completa las tareas
principales de su rol siguiendo solo su manual; un técnico instala el sistema en menos de 30
minutos siguiendo `manual_instalacion.md`.

Todos los manuales usan como referencia el mismo texto e íconos que aparecen en pantalla — si algo
cambia en la interfaz, se debe actualizar el manual correspondiente en la misma ronda.
